# Архитектура Country Search

## Отмена запросов и обработка ошибок

Поиском управляет `src/search/createSearchController.ts`.
При каждом изменении ввода `setQuery` сразу вызывает
`activeController.abort()`, а затем планирует новый поиск через debounce.

Отмена происходит до ожидания debounce: иначе старый запрос мог бы
завершиться и показать результаты под уже изменённым текстом.

Каждый поиск получает собственный AbortController. Его сигнал передаётся
в `searchCountries` и далее в fetch. Перед запуском запроса и после
получения данных контроллер проверяет, не отменён ли этот поиск.
Проверка дополняет настоящую отмену запроса и предотвращает обновление
состояния отменённой операцией.

В `src/api/searchCountries.ts` установлен таймаут 10 секунд.
Отдельный таймер отменяет запрос с причиной `TimeoutError`.
Внешний сигнал и сигнал таймаута объединяются через `AbortSignal.any`.
Таймер очищается в finally после завершения операции, включая чтение JSON.

Ответ 404 преобразуется в пустой массив. Другие неуспешные HTTP-статусы
вызывают HttpError, который хранит статус ответа. Ошибки сети передаются
вызывающему коду.

`src/api/getSearchErrorMessage.ts` различает ошибки:

- AbortError — сообщение не показывается;
- TimeoutError — сообщение о превышении времени ожидания;
- HttpError — сообщение с HTTP-статусом, кроме 404;
- остальные ошибки — общее сообщение о невозможности загрузить страны.

## Задержка debounce

Выбрана задержка 300 мс после последнего изменения ввода.

Без debounce запрос отправлялся бы на каждое нажатие клавиши.
Слишком большая задержка делала бы поиск медленным для пользователя.
300 мс уменьшают количество запросов при быстром наборе и сохраняют
достаточно быстрый отклик.

При очистке поля состояние сбрасывается. Запрос для пустой строки
не отправляется. Кнопка повтора запускает последний запрос сразу,
без ожидания debounce.

## Сложность mapCountryResponse

Функция находится в `src/countries/mapCountryResponse.ts`.

Обозначим:

- L — количество языков;
- B — количество граничащих стран;
- C — количество валют.

Временная сложность — O(L + B + C): функция проходит по языкам
и валютам и копирует массив границ. Остальные поля обрабатываются
за постоянное время.

Дополнительная память — O(L + B + C): создаются новый объект страны
и новые массивы языков, границ и валют.

## Принципы чистого кода

Ответственности разделены:

- `src/utils/debounce.ts` управляет задержкой вызовов;
- `src/api/searchCountries.ts` выполняет запрос и проверяет HTTP-статус;
- `src/countries/mapCountryResponse.ts` преобразует данные;
- `src/api/getSearchErrorMessage.ts` выбирает сообщение об ошибке;
- `src/search/createSearchController.ts` управляет состоянием поиска;
- `src/ui/createSearchView.ts` отображает состояние;
- `src/ui/createCountryDetails.ts` отображает подробности страны.

Маппер и функция выбора сообщения чистые: результат зависит от аргументов,
исходные данные не изменяются. Логика поиска не зависит от DOM.
Изменения состояния передаются интерфейсу через onStateChange.

Ранние возвраты обрабатывают пустой ввод, отмену и специальные HTTP-статусы,
уменьшая вложенность кода. Задержка debounce и таймаут вынесены
в именованные константы.

Динамический контент создаётся через DOM API и textContent.
innerHTML и insertAdjacentHTML не используются.

Тесты работают без реальной сети. Для времени используются fake timers,
для fetch — моки. Отдельный тест проверяет обратный порядок ответов
и реакцию мока на отмену сигнала.
